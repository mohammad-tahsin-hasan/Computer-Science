# Learning Platforms

A collection of online platforms, tutorials, and interactive resources for learning different subjects and developing new skills.

> **N.B.** This list is a work in progress. More learning platforms and resources may be added over time.

---

## 1. Artificial Intelligence (AI)

- [Google AI](https://ai.google/) — AI-related resources and information from Google.
- [Udacity](https://www.udacity.com/) — Online learning platform offering technology-focused courses and programs.

## 2. Programming

### General Programming

- [Codecademy](https://www.codecademy.com/) — Interactive programming lessons and courses.
- [W3Schools](https://www.w3schools.com/) — Tutorials and references for programming and web technologies.

### Language-Specific Interactive Practice

- **Python:** [Codédex](https://www.codedex.io/) — Interactive learning and practice for Python.
- **Java:** [CodinGame](https://www.codingame.com/) — Programming challenges and coding practice.
- **SQL:** [SQL Island](https://sql-island.informatik.uni-kl.de/) — Interactive SQL learning game.

## 3. Blockchain

- [101 Blockchains](https://101blockchains.com/) — Blockchain and related technology learning resources.
- [Coursera](https://www.coursera.org/) — Online courses and learning programs across different subjects, including blockchain.

## 4. Cybersecurity

### Learning Platforms and Training

- [Cybrary](https://www.cybrary.it/) — Cybersecurity learning and training resources.
- [SecurityTube](https://www.securitytube.net/) — Security-related video tutorials and learning materials. **Availability may need to be checked.**
- [TryHackMe](https://tryhackme.com/) — Hands-on cybersecurity learning platform.
- [Hacker101](https://www.hacker101.com/) — Free web security training.
- [PentesterLab](https://pentesterlab.com/) — Practical web security and penetration-testing exercises.
- [Hackademy](https://www.hackademy.co.in/) — IT training and services, including cybersecurity-related topics.
- [Alison](https://alison.com/) — Online courses across a range of subjects, including cybersecurity.

## 5. Machine Learning

- [Machine Learning Mastery](https://machinelearningmastery.com/) — Tutorials and practical guides for machine learning.
- [TensorFlow](https://www.tensorflow.org/) — Learning resources and documentation for the TensorFlow machine learning platform.

## 6. Data Science

- [Kaggle](https://www.kaggle.com/) — Data science learning resources, datasets, and competitions.
- [DataCamp](https://www.datacamp.com/) — Interactive courses for data science and analytics.

## 7. DevOps

- [KodeKloud](https://kodekloud.com/) — Hands-on DevOps and cloud technology training.
- [edX](https://www.edx.org/) — Online courses and programs from educational institutions and organizations.

## 8. Cloud Computing

- [Amazon Web Services (AWS)](https://aws.amazon.com/) — Cloud computing services, documentation, and learning resources.
- [JavaTpoint](https://www.javatpoint.com/) — Tutorials covering cloud computing and other technical subjects.

## 9. Analytics

- [CareerFoundry](https://careerfoundry.com/) — Online training programs, including data analytics.
- [Khan Academy](https://www.khanacademy.org/) — Free educational lessons and practice across a range of subjects.

## 10. Web 3.0

- [Buildspace](https://buildspace.so/) — Previously offered project-based Web3 learning. **The original Buildspace platform announced its closure in August 2024; this link is retained as a historical reference, not a current course recommendation.**
- [Web3 Foundation](https://web3.foundation/) — Resources related to Web3 and decentralized technologies.

## 11. Linux & System Administration

### Linux Tutorials, Commands, and Administration

- [LinuxOPSys](https://linuxopsys.com/) — Linux tutorials, commands, and system administration guides.
- [Linux Handbook](https://linuxhandbook.com/) — Practical Linux tutorials and guides.
- [Sysxplore](https://sysxplore.com/) — Linux and system administration learning resources.
- [Linuxize](https://linuxize.com/) — Linux tutorials, command guides, and system administration articles.

### Interactive Linux Learning

- [Linux Journey](https://linuxjourney.com/) — Guided lessons for learning Linux.
- [Linux Survival](https://linuxsurvival.com/) — Interactive Linux command-line tutorials.

## 12. General Course Resources

- [FreeCoursesSite](https://freecoursesites.com/) — Website listing course resources.
- [GeeksforGeeks](https://www.geeksforgeeks.org/) — Tutorials, articles, and learning resources across technical subjects.

## Notes

- Course availability, pricing, and free-access options may change.
- Some platforms offer both free and paid courses or features.
- Check each platform's terms, course details, and access conditions before enrolling.
- A resource being listed here does not imply endorsement or guarantee that every course is free.
