# 💻 Programming Languages

Welcome to the **Programming Languages** section! This directory contains code examples, practice solutions, and fundamental concepts organized by programming language and topic.

---

## 📂 Languages Covered

### 1. [C](Codes/C/)
Comprehensive C programs covering foundational programming constructs, memory management, and data handling:
- **[Basics & Operators](<Codes/C/Basics & Operators>)**: Arithmetic, conditionals, input/output, and problem solving.
- **[Loops & Patterns](<Codes/C/Loops & Patterns>)**: While/for loops, range summation, pattern printing, and prime number algorithms.
- **[Arrays](<Codes/C/Arrays>)**: 1D arrays, search, reverse, insert, delete, frequency counting, and palindromes.
- **[Strings](<Codes/C/Strings>)**: Character arrays, string functions, anagrams, palindrome strings, and case conversion.
- **[2D Arrays & Matrices](<Codes/C/2D Arrays & Matrices>)**: Matrix operations (addition, multiplication, transpose, diagonal/magic matrix verification).
- **[Pointers & Dynamic Memory](<Codes/C/Pointers & Dynamic Memory>)**: Pointer arithmetic, pass-by-reference, and `malloc` dynamic memory allocation.
- **[File IO](<Codes/C/File IO>)**: File reading/writing, structs, error handling with `perror`, and file merging.

### 2. [C++](Codes/Cpp/)
Core C++ implementations emphasizing modern features, custom comparators, and Object-Oriented Programming (OOP):
- **[Basics & Conditionals](<Codes/Cpp/Basics & Conditionals>)**: Standard I/O, conditionals, mathematical operations, and patterns.
- **[Loops & Math](<Codes/Cpp/Loops & Math>)**: Factorials, primality testing, and number properties.
- **[Arrays & Numbers](<Codes/Cpp/Arrays & Numbers>)**: Array operations, element searching, and target sum checks.
- **[Strings](<Codes/Cpp/Strings>)**: String streams, word searching, sentence reversal, and anagram checks.
- **[2D Arrays & Matrices](<Codes/Cpp/2D Arrays & Matrices>)**: Multi-dimensional matrix operations in C++.
- **[Sorting & Custom Comparators](<Codes/Cpp/Sorting & Custom Comparators>)**: `std::sort`, dynamic array sorting, and custom comparator functions for pairs and complex types.
- **[Classes & OOP](<Codes/Cpp/Classes & OOP>)**: Object-Oriented Programming with classes, encapsulation, member methods, and multi-criteria sorting.
